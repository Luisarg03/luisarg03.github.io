solution: "Servidor MCP en Python respaldado por SQLite FTS5 + vault OKF en Markdown con templates y type registry. Dos plugins Cordis: memory-mcp (wrapper stdio que conecta DSH al vault) y memory-auto (captura automática con digests de sesión y checkpoints en commits/compactions). Los digests corren in-process vía el LLM del propio harness — sin CLI externa ni credenciales almacenadas. Resolución de rutas independiente del cwd: env vars, harness home y profile patch."

  - "Memoria persistente por proyecto: hechos, decisiones, aprendizajes, convenciones y perfil en OKF (Markdown + índice SQLite FTS5)"

  - "Cero credenciales extra: los digests usan el mismo LLM y key con que DSH ya está configurado"
  - "Instalación como plugins Cordis: dsh plugin add en un perfil, con override por env / harness home / profile patch"
